# Autonomous strategy research memory

Cloud strategy reviews now receive an inventory of active input families, the last 20 persisted trials with outcome summaries, and available matched-coin comparisons. Full prior trial rules and reports remain in SQLite across restarts. Required fields describe which inputs a rule uses, not proof of a trading pattern. Breakouts or pullbacks cannot be claimed without actual price-history features.

Cloud admission limits crowded entry structures: if two active or queued candidates have the same entry syntax tree with numeric thresholds removed, further variants are retained as diversity_blocked proposals instead of occupying another slot. Changing names or numeric thresholds does not bypass this gate. Existing trials, laptop submissions, risk limits, budgets and promotion requirements are unchanged. This is a structural filter, not a complete semantic equivalence detector.

Every new cloud proposal records its research family, required fields, the closest existing reference rule, its immutable reference copy, and which expressions changed. Refinements prefer changing only entry or exit. Comparisons begin after candidate admission and the saved experiment timestamp; only coins actually closed by both rule versions count. Pre-admission entries, future closes, unmatched coins and coins still held by any Jarvis/research portfolio are excluded. Dollars include recorded costs and write-offs. These matched observations are not randomized causal evidence, do not equal identical fill times/exposure, and never promote a strategy. Existing 100-distinct-coin prospective profitability and robustness gates stay authoritative.

The cloud brain uses this evidence in subsequent scheduled or 100-coin reviews, within its existing budget. Heavy comparison queries run during research job preparation, not on every trading tick. No new external data calls, subscription, laptop update, balance reset or real-money permission is added. The investigation page shows the saved experiment design on new strategy proposals.
